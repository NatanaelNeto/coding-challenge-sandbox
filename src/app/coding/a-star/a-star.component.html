A* Algorithm

This was the most fun project I've done so far. It uses the classic A* algorithm, with Euclidean distance as a heuristic. I love the way this algorithm works. A few years ago, I did a similar project for my Computer Science course (it is available here), but it had some errors. So, I decided to fix it.

I had some difficulties here. First of all, how exactly does the A* algorithm work? I knew the theory and had done this project before, but I didn't want to go back to my GitHub and just copy the code and paste it here. I needed to do it from scratch.

I searched for some videos on YouTube to visualize the A* algorithm and reproduce it with TypeScript. Initially, the algorithm I made worked almost perfectly, but I didn't handle some edge cases (like diagonal paths), and my first attempt took a long time to deliver a result.

First things first, I adjusted the algorithm to consider diagonal paths. However, when it reached a 'chessboard' point (as seen in the figure), it just crossed the walls, which is not acceptable. To fix this, I coded it to check the vertical/horizontal adjacent neighbors. If both are walls, the current neighbor is marked as unreachable.
